Blender .blend thumbnails in Windows Explorer

SageThumbs 2K shows the preview picture Blender stores in each .blend file, so your scenes appear as thumbnails in File Explorer. Blender's numbered backups, .blend1 to .blend32, get the same treatment.

What you see

  • The thumbnail is the preview Blender saved into the file. SageThumbs reads it straight out of the .blend; it does not open or render the scene.
  • Backup copies, .blend1 through .blend32, show their own stored preview, so you can tell versions apart before opening one.
  • Large .blend files are not loaded whole. The preview is pulled out of the file directly, so the preview pane stays quick even for heavy scenes.

Limits

  • What you see is the stored preview, not a fresh render: the scene as it was when the file was saved.
  • Online-only files in OneDrive and other synced folders keep their icon: nothing is downloaded just to draw a thumbnail. Files stored on the PC get thumbnails there as anywhere else.

More you can do

  • Press Space on a .blend for a larger look in Quick preview, or use the Explorer preview pane, without starting Blender.

Thumbnails not showing?

  • Windows caches thumbnails, and a file it failed on once stays failed. In SageThumbs, Settings ▸ Advanced ▸ Rebuild thumbnail cache clears the cache and restarts Explorer.
  • Make sure File Explorer's "Always show icons, never thumbnails" option is off, and that the format is ticked in SageThumbs Settings ▸ File types.
  • Run st2k doctor in a terminal. It only reads, checks the whole chain, and prints a fix under anything that is wrong.
