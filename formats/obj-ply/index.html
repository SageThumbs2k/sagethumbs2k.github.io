OBJ and PLY 3D model thumbnails in Windows Explorer

OBJ and PLY files carry no preview image. SageThumbs 2K reads the mesh and renders a shaded thumbnail of it in File Explorer, for models exported from 3D apps and for 3D scans alike.

What you see

  • The mesh is drawn flat-shaded from a consistent three-quarter angle on a transparent background, the same way for every file in the folder.
  • Dense scans are streamed: millions of triangles are drawn as the file is read rather than loaded into memory first.
  • Quick preview (press Space) shows the same rendering at full size.

Limits

  • The thumbnail shows the shape as plain shaded geometry from one fixed angle.
  • Geometry is read defensively: invalid coordinates are dropped and the drawing work is capped, so a damaged file cannot stall Explorer.
  • Online-only files in OneDrive and other synced folders keep their icon: nothing is downloaded just to draw a thumbnail. Files stored on the PC get thumbnails there as anywhere else.

Thumbnails not showing?

  • Windows caches thumbnails, and a file it failed on once stays failed. In SageThumbs, Settings ▸ Advanced ▸ Rebuild thumbnail cache clears the cache and restarts Explorer.
  • Make sure File Explorer's "Always show icons, never thumbnails" option is off, and that the format is ticked in SageThumbs Settings ▸ File types.
  • Run st2k doctor in a terminal. It only reads, checks the whole chain, and prints a fix under anything that is wrong.
