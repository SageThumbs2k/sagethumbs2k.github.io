# sagethumbs2k.github.io

The website for **SageThumbs 2K**, a crash-isolated Rust shell extension that gives Windows 11
File Explorer thumbnails for hundreds of file types Windows can't read: RAW, PSD, HEIC, video,
ebooks, 3D models, plus Quick Look, email preview, convert, resize and OCR.

[![Discord](https://img.shields.io/badge/Discord-join_the_community-5865F2?logo=discord&logoColor=white)](https://discord.gg/PsWpeNUzhk)

- **Live:** https://sagethumbs.lunarwerx.com
- **The app:** https://github.com/LunarWerxs/SageThumbs-2k
- **By:** [LunarWerx Studios](https://lunarwerx.com)

A static site served by GitHub Pages from `main` at the root. Edit `index.html`, push, and
Pages redeploys. `CNAME` holds the custom domain.
